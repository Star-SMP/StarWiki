# 🎮 Как начать играть?
Выполните несколько действий, чтобы зайти к нам на сервер.
##
1. Получите проходку:
- **Бесплатно** - Напишите заявку в канале `#заявка` на нашем [Дискорд сервере](https://discord.gg/starsmp);
- **Платно** - Купите проходку у нас в [магазине](https://shop.starsmp.fun/).

2. Зайдите на сервер по IP: `starsmp.fun`;

3. Пройдите регистрацию и привяжите свой дискорд к игре, написав высветившийся на экране код в лс боту `StarBot#7765`;

4. Перезайдите на сервер и наслаждайтесь игрой!
::: tip Привязка 2FA
Вы можете дополнительно обезопасить свой аккаунт, прописав на сервере команду `/addds`.
:::
::: tip Вход без `/login`
Если вы обладаете **лицензией** Minecraft, то введите команду `/premium` на сервере, чтобы вам не приходилось постоянно вводить пароль.
:::
