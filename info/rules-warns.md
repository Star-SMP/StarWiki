# Виды наказаний
На нашем сервере действует своя система наказаний - муты, варны и баны.

Уведомления о наказаниях отправляются в канал `#уведомления`.
## Мут
Временное лишение возможности отправлять сообщения в чат, обычно выдается за многочисленные нарушения в самом чате.
## Оранжевый варн
Один из видов предупреждений, который имеет срок действия. При его истечении варн снимается. Обычно выдаётся за незначительные нарушения, например в чате.
::: warning Примечание
При наличии у игрока 3 активных оранжевых варна они конвертируются в **красный варн**.
:::
## Жёлтый варн
Один из видов предупреждений, который имеет срок действия. Выдаётся за нарушение игровых правил, в причине указывается условие, которое игрок должен выполнить до истечения времени.
::: warning Примечание
При истечении срока действия жёлтого варна игрок получает **красный варн**, а жёлтый варн **возобновляется**.
:::
## Красный варн
Один из видов предупреждений, который **не имеет** срока действия. Его нельзя никак снять, и выдаётся за более серьёзные нарушения.
::: warning Примечание
При наличии у игрока 3 активных красных варна он получает **бан(навсегда)**.
:::
## Бан
Блокировка аккаунта на сервере, может быть временным и бесконечным. Обычно выдаётся за предел красных варнов и попытки навредить серверу.
::: tip Получение разбана
Игрок может быть разбанен, если откроет тикет, где он может обжаловать наказание или приобрести разбан за реальные деньги. Цена за первый разбан является начальной для игрока, которая с каждым разом будет умножаться на x1.5. После приобретения игрок также получает 1 красный варн как мера предосторожности.
:::
