# 🎭 Скины
## Как поставить любой скин
На наш сервер можно зайти без лицензии, поэтому у игроков есть возможность ставить скины по нику:

`/skin <ник>`

Найти скины по нику можно на сайте [namemc.com](https://namemc.com).

## Как поставить скин по URL
Если на NameMC нет того скина, который вы нашли на просторах интернета, или вы нарисовали свой скин, то можете использовать `/skin url <ссылка.png> <classic/slim>`. Важно вставить правильную ссылку, чтобы скин отобразился на сервере, для этого следуйте дальнейшим инструкциям:

1. Загрузите свой скин на [imgur.com](https://imgur.com/) (если не получается, используйте VPN).

2. Нажмите на `...` возле картинки и `Get share links`

![image](../.vitepress/assets/chrome_XWtUDT4c8s.png)

3. Найдите поле `BBCode (Forums)` и скопируйте оттуда содержимое

![image](../.vitepress/assets/chrome_NcltLsWkoO.png)

4. Вставьте ссылку в команду, обязательно убрав у неё по бокам `[img]` и выберите стиль скина (`classic/slim`)
::: tip Пример команды
`/skin url https://i.imgur.com/eizw3SJ.png classic`
:::

Теперь вы можете устанавливать вообще любые скины на сервере.
