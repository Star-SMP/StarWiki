# Запрещённые модификации
::: info **`3.2`** Запрещено использование читов и сторонних программ 
Любые читы, моды и программы, дающие  сильное  преимущество над другими игроками, запрещены.
::: warning Исключения
Баги/модификации разрешённые администрацией.
:::
## Список запрещенных модификаций
- Модификации, которые выполняют действия за игрока (ИИ, принтеры, автокликеры и т.п.);
- Программы, сайты и моды для поиска и использования сида мира;
- Любой чит-клиент, X-Ray и аналогичные моды, дающие большое преимущество в игре;
- Любые модификации с похожим или идентичным функционалом, как у других модов из списка запрещённого ПО;
- Tweakeroo;
- Freecam (Разрешен только от Modrinth);
- Моды для авто-рыбалки (можно использовать механизмы для AFK-рыбалки);
- No Mining Cooldown;
- Ghostblocks;
- Automatic Tool Swap;
- Inventorio;
- Accurate Block Placement и Accurate Block Placement Reborn;
- nofog/Lava Clear View и подобные моды;
- Librarian Trade Finder;
- JJElytraSwap;
- Inventory profile next.
::: danger Внимание!
Если какого-то мода нет в этом списке, то это не значит, что он разрешен, лучше уточните это в **тикете**.
:::
