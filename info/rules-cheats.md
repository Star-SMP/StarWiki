# Запрещённые модификации
::: info `3.10.` Запрещено использование любых читов, модификаций, скриптов или утилит, предоставляющих преимущество перед другими игроками. К таким относятся: запрещённые модификации, X-Ray, KillAura, автокликеры, макросы на автоматическое действие, ESP и другие программы, изменяющие механику клиента или взаимодействие с сервером. Использование сомнительных модов рекомендуется предварительно согласовывать с администрацией. Любая попытка скрыть использование запрещённого софта расценивается как отягчающее обстоятельство.
::: warning Исключения
Баги/модификации разрешённые администрацией.
:::
## Список запрещенных модификаций
- Модификации, которые выполняют действия за игрока (ИИ, принтеры, автокликеры и т.п.);
> Разрешено использовать автокликер только на фермах где требуется длительное взаимодействие игрока
- Программы, сайты и моды для поиска и использования сида мира;
- Любой чит-клиент, X-Ray и аналогичные моды, дающие большое преимущество в игре;
- Любые модификации с похожим или идентичным функционалом, как у других модов из списка запрещённого ПО;
- Tweakeroo;
- Freecam (Разрешен только от Modrinth для красивых кадров);
- Моды для авто-рыбалки (можно использовать механизмы для AFK-рыбалки);
- No Mining Cooldown;
- Ghostblocks;
- Automatic Tool Swap;
- Inventorio;
- Accurate Block Placement и Accurate Block Placement Reborn;
- nofog/Lava Clear View и подобные моды;
- Librarian Trade Finder;
- JJElytraSwap;
::: danger Внимание!
Если какого-то мода нет в этом списке, то это не значит, что он разрешен, лучше уточните это в **тикете**.
:::
