# 👨‍💻 Команды

## Базовые команды
| Команда          |           Описание            |
| ---------------- | :----------------------: |
| `/features` | узнать самые важные фишки сервера |
| `/skin` | изменить скин | 
| `/settings` | настройки игры на сервере |
| `/cosmetics` | меню с косметикой |
| `/msg` `/m` `/dm` `/pm`  `/w` | отправить личное сообщение игроку |
| `/reply` `/r` | ответить на личное сообщение |

## Авторизация
| Команда          |           Описание            |
| ---------------- | :----------------------: |
| `/register` `/reg` | зарегистрироваться |
| `/login` `/l` | авторизоваться |
| `/changepass` `/cp` | сменить пароль |
| `/premium` | заходить на сервер без пароля, если есть лицензия |
| `/cracked` | вернуть вход с  паролем на лицензии |
| `/2fa` | двухфакторная аунтефикация (доп. защита аккаунта) |

## Фишечные команды
| Команда          |           Описание            |
| ---------------- | :----------------------: |
| `/starpass` | прогрессия по достижениям за старкоины |
| `/border` `/barrier` | продвижение границы во всех мирах |
| `/sign` | подписать предмет |
| `/afk` | | встать в афк |
| `/marks` | марки на карте, особые места на сервере |
| `/leaders` | таблица лидеров |
| `/sit` `/lay` `/crawl` `/spin` | позы |
| `/rewards` | ежедневные награды |
| `/groups` | группы голосового чата |
| `/ignore` `/unignore`  | настройки видимости сообщений от игрока |
| `/ignorelist` | список игроков в игноре |
| `/ic list` | список парсеров в чат |
| `/do` `/me` `/try` `/dice` | рп команды |
