# 🖼 Взаимодействия с рамкой

| Действие          |           Описание            |
| ---------------- | :----------------------: |
| `Shift + ПКМ` + ножницы | делает рамку невидимой |
| `Shift + ПКМ` + стекл. панель | фиксирует положение предмета |
| `Shift + ПКМ` + цепь | блокирует предмет в рамке |
| `Shift + ПКМ` + кисть | сбрасывает все изменения |
