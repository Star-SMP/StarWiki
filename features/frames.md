# 🖼 Взаимодействия с рамкой
Кликнув `ПКМ` по рамке **ножницами**, она станет **невидимой**.

Кликнув `ПКМ` по рамке **стеклянной панелью**, вы **зафиксируете** положение предмета в ней.

Чтобы вернуть все свойства обычной рамки, кликните `ПКМ` по ней **кистью**.
