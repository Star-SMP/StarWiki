# 🗺️ Онлайн карта
На сервере доступна онлайн карта, с помощью которой вы можете просматривать мир, видеть постройки игроков и их местоположение.

| Команда          |           Описание            |
| ---------------- | :----------------------: |
| `/map show` | показать себя на карте |
| `/map hide` | скрыть себя на карте |

Посмотреть карту можно [тут](https://map.starsmp.fun/).
