# 🪑 Позы
Плагин на позы, с помощью которого можно садиться, ложиться, ползать, крутиться и даже сидеть на голове у игрока.

Чтобы сидеть, используйте команду `/sit` или `ПКМ` по ступеньке, полублоку или ковру. Действующий слот должен быть пустым.

Чтобы лежать на спине, используйте `/lay`.

Чтобы лежать на животе, используйте `/bellyflop`.

Чтобы ползать по полу, используйте `/crawl`.

Чтобы крутиться на месте, используйте `/spin`.

Чтобы сидеть на голове у игрока, нажмите `ПКМ` по игроку, действующий слот должен быть пустым. Чтобы убрать игрока со своей головы, нужно нажать `shift`.
