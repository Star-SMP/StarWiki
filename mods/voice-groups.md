# 👨‍👨‍👧‍👦 Группы
С помощью групп PlasmoVoice вы можете создать голосовой канал и общаться на любом расстоянии с ее участниками.

## Доступные команды
`/groups` или `/groups browse [страница]` — просмотреть группы;

`/groups create [...флаги]` — создать группу;

`/groups invite <игрок>` — пригласить игрока в группу;

`/groups join <UUID группы> [пароль]` — присоединиться к группе (лучше использовать приглашение или поиск);

`/groups info` — информация о группе;

`/groups leave` — покинуть группу;

`/groups set <флаг> <значение>` — устанавливает значение флага;

`/groups unset <флаг>` — устанавливает значение флага по умолчанию;

`/groups delete` — удалить группу;

`/groups transfer <игрок>` — передать лидерство группы другому игроку.

## Доступные флаги
`name` — название группы;

`password` — пароль.
