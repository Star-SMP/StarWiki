# 📦 Ресурспак
У сервера есть собственный ресурспак, он является обязательным для установки, ведь без него не будет работать большая часть функций. Также в ресурспаке имеются именнованые тотемы:

**Основатели** - Имеют по 2 тотема (2D и 3D)

**3D Тотемы** -  harokii, pixiemays.

**2D Тотемы** - harokiii, pixiemayss.

**Администрация** - aloemic, kisva, notsnkja, punkflash, valcrons, yokixq.

**Легенды** - 20000timoha, artgo1, asqdsq, chilimx90, dorcy, elusia, fukinkou, marquis, nothingness, steevedeadpool, zxcfloax, capskary.
