# 🍰 Больше еды и напитков
Данный датапак добавляет более 60 рецептов блюд и новый способ их готовки - **"Кулинарная станция"**.

Чтобы узнать рецепты, вам нужно скрафтить "**Книгу рецептов**" из хлеба и книги с пером.

::: warning Внимание!
Использование ресурспака ОБЯЗАТЕЛЬНО. Без него функционал датапака работать не будет.
:::
